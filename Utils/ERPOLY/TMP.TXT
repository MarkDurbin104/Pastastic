
Function	DoPolyErase

Synopsis	Erase the polygon by rectangular region

Prototype	BOOL DoPolyErase(XYPOINT *poly,int numply,int increment);

Module	ERASEPLY.C

Description	Erase the polygon by passing over each point in the polygon in the  direction top to bottom and marking all the intersecting blocks for deletion once the entire polygon has been covered, any adjacent rectangles of the same width are merged. 

Passed	XYPOINT *poly  - The polygon points
	int numply  - The number of points in the polygon
	int increment  - The minimum height of each rectangle

Return Value	BOOL  - always TRUE

Called By	erase_polygon.

Calls	GetUpLowBounds, GetPointsofIntersection, YAdjRect, EraseRect.

See Also	EraseRect, erase_polygon, GetAngle, GetPointsofIntersection, GetUpLowBounds, Imcmp, YAdjRect.


Function	EraseRect

Synopsis	Call the GMLI erase_region command for each rectangle in the list

Prototype	void EraseRect(PLIST *p);

Module	ERASEPLY.C

Description	Call the GMLI erase_region command for each rectangle in the list, as each region is erased free the memory associated with the rectangle's list entry 

Passed	PLIST *p  - The first element in the rectangle point list

Return Value	None

Modifies	p 

Called By	DoPolyErase.

See Also	DoPolyErase, erase_polygon, GetAngle, GetPointsofIntersection, GetUpLowBounds, Imcmp, YAdjRect.


Function	erase_polygon

Synopsis	erase a polygon using rectangular regions - called by GML

Prototype	BOOL erase_polygon(void);

Module	ERASEPLY.C

Description	This function is called repeatedly to collect arguments off the command line from GMLI on the first call the three parameters "add" the number of polygons and the increment size should be passed. On subsequent  calls the parameters should be the X and Y co-ordinates of one point in the polygon.  When all the points have been collected this function then calls DoPolyErase to do the work and then it frees the memory allocated  for the polygon points and returns FALSE. Any failure will also return FALSE 

Return Value	BOOL  - TRUE if more parameters are required else FALSE

Modifies	numpolypoint currentpolypoint 

Calls	DoPolyErase.

See Also	DoPolyErase, EraseRect, GetAngle, GetPointsofIntersection, GetUpLowBounds, Imcmp, YAdjRect.

Function	GetPointsofIntersection

Synopsis	Get all the points along a line that are intersected by the polygon

Prototype	NUMB *GetPointsofIntersection(NUMB y,XYPOINT *poly,int numply);

Module	ERASEPLY.C

Description	Get all the points along a line that are intersected by the polygon, returning a list sorted from left to right 

Passed	NUMB y  - The Y co-ordinate if the line
	XYPOINT *poly  - The polygon points
	int numply  - The number of points in the polygon

Return Value	NUMB *  - a sorted list of points, (-1) indicating the end of the list             

Modifies	poly 

Called By	DoPolyErase.

Calls	GetAngle, Imcmp.

See Also	DoPolyErase, EraseRect, erase_polygon, GetAngle, GetUpLowBounds, Imcmp, YAdjRect.
