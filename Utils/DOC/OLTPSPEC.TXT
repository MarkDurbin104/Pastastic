SCANBAR.EXE     -   Scan a barcode generated by BARTM270

    SCANBAR will return TRUE if a barcode has been read.  The barcode
    information will be converted and placed in a file called
    BARVALUE.OLT and the format of that file will be as follows :
    
        [SSS DDD dd mm y NNNNN]
        SSS     -   3 character source post code
        DDD     -   3 character destination post code
        dd      -   2 digit day code between 01 and 31
        mm      -   2 digit month code between 01 and 12
        y       -   1 digit year code between 0 and 9
        NNNNN   -   5 digit integer between 00000 and 46656
    
    Each parameter in the file will be seperated by a SPACE thereby
    giving a fixed record length of 21.
    If a key is pressed prior to reading a barcode, SCANBAR will
    return FALSE and the contents of the file BARVALUE.OLT will 
    not have been changed.

CALCVAL.EXE     -   Calculate the value of a parcel

    CALCVAL will take 3 arguments
        argv 1  -   International Zone between 0 and 4 (0 Home country)
        argv 2  -   Type of delivery i.e. Normal/Recorded 
        argv 3  -   Weight in Kilos

    more information will be required before these parameters can be
    explanded upon.
    CALCVAL will return a value in pence/cents
        i.e.   1045 = $10.45

BARTM270.EXE    -   Print a barcode on the TM270 serial printer

    BARTM270 takes 6 arguments

        argv 1  -   3 character source post code
        argv 2  -   3 character destination post code
        argv 3  -   day code
        argv 4  -   month code
        argv 5  -   year code
        argv 6  -   unique integer between 0 and 46656

        e.g.  a parcel going from Dartford (DA1) to Citygate (SE1)
              on 14 June 1991 would require the following command line.

        BARTM270 DA1 SE1 14 6 91 0

        Note :  only the least significant digit of the year code will
                be used.  Therefore only a ten year resolution can be 
                achieved with a 14 digit barcode.
