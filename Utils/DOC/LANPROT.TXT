    Setup.
            Requester       Passthru        Sender

              зддд© REQддд>  зддд©          зддд© 
              Ё R цдддддддддд╢ P цдддддддддд╢ S Ё
              юддды          юддды <дддFILE юддды

              Node 2         Node 1         Node 0

    Overview.

        Node 2 requests a file from node 0 this request goes via node 1 
    to node 0.  The file is then sent via node 1 to node 2 from node 0.

    
    The transmition header

        Before any transfer a 16 byte header is sent from the
    transmitting machine this header contains information such as :

        rx node
        tx node
        service required
        etc...

        in the case of the setup below, this header is transmitted
    from 'R' to 'P', 'P' recognises the header is not for 'P' and
    re-transmits it to 'S'.
